## The 3090 replication arithmetic, through the shipped code path

`plan --total 117.6 --active 8.4 --bits 3.75 --vram 24 --vram-bw 936 --ram 64 --ram-bw 86
--disk-bw 3` → **10.6 tok/s** hybrid row, with the pinned-memory warning firing on his exact

## What this does and does not prove

**Proven:** on the reference machine, the v1.19 chain (measure → predict → command → run) is
self-consistent to +9%, with every stage the shipped artifact. The 9× failure mode E-06 reported
cannot recur from the causes found: the channel bug is fixed and tested, calibration replaces
assumption, and the command carries the flags whose absence cost him 2.5×.

**Not proven, and only a second machine can:** (a) the stream-realism transfer assumption
(calibrate's peak-conversion uses this box's 0.544 delivered/peak ratio; DDR5 platforms may sit
elsewhere); (b) the GPU eta classes for Ampere+ remain [table] spec guesses; (c) fork-specific
behavior. These are exactly what the E-06 rerun ask measures — and if his rerun misses the band,
that is the next E-entry, published loudest.
