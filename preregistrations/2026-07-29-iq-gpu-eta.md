# Pre-registration #70: the IQ GPU eta — pricing the last named accuracy defect

**Author:** Federico Sciuca · **Date staked:** 2026-07-29, BEFORE any run. **STAKED.**

## The mechanism bet

U-17 (v1.21) closed the CPU side of the IQ pricing gap: the #66 pure-CPU IQ arm is now exact
(11.4 predicted vs 11.44 measured). The split arm improved but stayed **+14% over** (26.9 vs
23.60) — and the register's U-19 names the residual: the GPU share of an IQ file is still priced
at K-quant eta, because `spec.FORMAT_EBW` has no IQ entries (`fmt_bw: None` on IQ2_XS). V-11's
matched pair already measured IQ decode slower on GPU; the number exists, it is just not in the
ladder. This prereg measures it properly and wires it.

## Protocol

Same-session matched set on Qwen2.5-7B-Instruct, all-in-VRAM (`llama-bench -ngl 99 -n 128 -r 3`,
tg128, clocks logged before/after per C-10 discipline):

- **Q4_K_M** (control — its FORMAT_EBW entry 106.4 anchors the conversion)
- **IQ2_XS** (fetched fresh via `quantprobe fetch --force`-guarded path; the format DS-Lite is 96% made of)
- **IQ3_XS** (on disk; #16 measured 18.11 on an earlier session — doubles as a session-state check)
- **IQ3_M** (on disk; bonus ladder point)

Derivation is matched-pair, immune to active-byte convention drift:
`ebw_IQ = 106.4 × (tokps_IQ / tokps_Q4KM)` from the same session.

## Stakes

- **P-1 (direction, L-15/V-11).** Every IQ format's derived ebw lands **≥10% below** Q4_K's
  106.4 — IQ unpack is ALU-heavy and Pascal pays it in decode, despite IQ moving fewer bytes.
- **P-2 (THE WIRING — out-of-sample).** With the measured IQ2_XS entry in FORMAT_EBW, the #66
  DS-Lite split-arm retrodiction moves from +14% over to **inside the band on the honest side:
  −25%..+5%** against the measured 23.60. The pure-CPU arm must stay exact (11.4) — it has no
  GPU term, so any movement there means the wiring leaked.
- **P-3 (session-state check).** Fresh IQ3_XS reproduces #16's 18.11 within ±10%.

## KILL RULE

If P-2 over-corrects past −25%, the GPU-side story is insufficient and the IQ entries do NOT
ship — U-19 is amended with the refutation and the split residual stays open with a new
hypothesis owed. If P-1 fails (IQ decodes at K-quant parity per byte), U-19's premise is dead
and the +14% needs a different mechanism entirely. Misses publish with the same prominence as
hits, as always.

**Wired into:** `spec.FORMAT_EBW` IQ entries (measured, shipped) + `t_prereg70_iq_format_ladder`;
U-19 scored REFUTED-as-hypothesized; the residual reattributed as U-20.

**Protocol disclosures, before the verdicts.** (1) The staked derivation line omitted the bytes
ratio; effective bandwidth is tok/s × bytes-per-token — the convention every existing FORMAT_EBW
entry uses — and that is what was computed. (2) IQ2_XS came from mradermacher (bartowski's repo
has none); imatrix changes values, not the kernel, so the eta is the format's. (3) IQ4_NL was
added AFTER staking, forced by a discovery: DS-Lite's "IQ2_XS" file is only 51% IQ2_XS — 45% of
its bytes are IQ4_NL. The earlier iq_share=0.96 lumped all IQ-prefixed types.

- **P-1 HIT on the staked set — and the exploratory arm breaks the generalization.** All three
  staked IQ formats land 36–52% below Q4_K. But IQ4_NL lands at 117, BESIDE Q4_0 (119.1): had it
  been staked, P-1 would have missed. The honest mechanism statement is **codebook vs not**, not
  IQ vs K: IQ2/IQ3 pay their grid lookup in decode; IQ4_NL's kernel is Q4_0-class. "IQ is slow"
  is hereby scoped down, including in our own prior prose (V-11's 2.7x is codebook-CPU).
- **P-2 MISS — and the diagnosis reattributes the residual.** With the entries wired, the
  anchored DS-Lite split retrodiction moves 26.9 → 26.5 vs 23.60 measured (+12.3%, outside
  −25..+5). Traced to the root: on the calibrated path the GPU was priced at geta 0.35 × ratio
  0.754 = 0.264 effective eta — coincidentally at pure-IQ2_XS speed (0.266) ALREADY, and the
  honest measured blend (0.43, dragged up by the 45% IQ4_NL) makes the GPU pricing FASTER.
  U-19's premise ("the GPU share is priced at K-quant eta") was simply false on this path.
  With the CPU tier exact (11.4 vs 11.44) and the GPU tier now measured-priced, the +12%
  residual must be STRUCTURAL to the split placement — and #27's decomposition already measured
  the candidate at matching magnitude: 7.4–11.1 ms/token of GPU<->CPU sync excess (17–25% of a
  token) that no per-tier byte pricing captures. Registered as **U-20**.
- **P-3 MISS.** Fresh IQ3_XS 20.29 vs #16's 18.11 = +12.0%, outside ±10%. Consistent with the
  C-10 boost-state history — #16 predates the stuck-boost diagnosis, so its session state is
  unknown. Today's clocks are logged.

**Kill-rule outcome:** the kill clause (over-correction past −25%) did NOT fire — the entries
are measurements and they ship (they fix a real under-pricing for IQ4_NL-class files, which the
old path priced at 0.264 effective eta against a measured 0.61). U-19 is scored REFUTED as
hypothesized; the split residual stays open under U-20 with a measured suspect.
